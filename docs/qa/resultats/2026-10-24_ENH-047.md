## Ecarts
- **[bloquant] Fichier corrompu ou tronque -> code 0, aucune annonce.** Repro : `enhance-bench --stage decode --in tests\clips\gen\edge_corrupt.mp4 --report r.json` (idem `edge_truncated.mp4`) -> code 0, `warnings` vide, `error` nul, fps rapporte comme une mesure valide. Attendu : critere ENH-047 « code != 0 avec message clair sur ... corrompu » et seuils QA § 4.4 / § 4.2 « decodage partiel annonce ». Correctif suggere (gpu-engineer) : remonter du demux / decodeur le nombre de paquets rejetes ou « erreur de decodage », puis soit code 2 `SourceCorrupt`, soit au minimum un avertissement dans `warnings[]` + message sur stderr (le critere stricte demande le code != 0). Ajouter les deux clips `edge_*` au test GPU `CodesDeSortie` (le test actuel n'utilise que du bruit pur, qui n'est pas le cas realiste). Re-QA limitee a ces cas.
- **[mineur] Instabilite du debit VSR entre processus** : ecart inter-passes 7,6-9,9 % dans 3 sessions sur 5 (> 3 %), medianes de session de 294 a 341 i/s (jusqu'a 15 % d'une session a l'autre), a charge GPU externe equivalente (0-6 %). Cause probable : etat d'horloge / temperature du GPU (SM 1200 -> 2750 MHz). `Measure-Speed` ne l'evite pas (la serie « calme » a 0,4-0,6 % est une exception). Signale, non masque, pas de relance pour un meilleur chiffre. Consequence : la regle « regression > 5 % » ne peut pas comparer deux sessions differentes pour VSR ; comparer main et branche **dans la meme session, en alternance** (ou ajouter un chauffage GPU / verrouillage d'horloge dans le protocole, a decider avec le PO).
- **[mineur] `repeats[]` en decodage** : chaque passe dure ~67 ms ; la dispersion intra-processus (1,2-13 %) depasse souvent 3 %. A documenter : la repetabilite se calcule sur les medianes de processus, ou utiliser `--repeat` avec des passes plus longues (`--max-frames` ne suffit pas, il raccourcit). A noter dans `docs/gpu/ENH-047.md` § 8.4.
- **[info] `Measure-Speed.ps1`** : `-InputFiles` ne s'accepte pas en liste separee par des virgules avec `pwsh -File` (une seule chaine) : appeler depuis un script avec un tableau. Sans impact sur le banc.
- **[info]** `docs/qa/resultats/2026-10-24_1854_feature-ENH-047-enhance-bench.md` (rapport test-gpu) est non suivi, comme prevu.
